Discrete Flappy Bird - DE10-Lite FPGA / SystemVerilog / Quartus

The project documentation is now maintained in Markdown:

  README.md
    Project overview, controls, system block diagram, source file list,
    and quick-start build instructions.

  docs/DESIGN.md
    Detailed RTL documentation, state diagram, input and display block
    diagrams, timing, movement, collision detection, and scoring.

  docs/HARDWARE_AND_QUARTUS.md
    Hardware connection diagram, matrix polarity and package-pin mapping,
    Quartus setup, hardware bring-up, and troubleshooting.

The original matrix wiring table and row-resistor notes have been
consolidated into docs/HARDWARE_AND_QUARTUS.md. Exact FPGA GPIO assignments
are not supplied. Verify the board and matrix part before reproducing
the physical wiring.

Open README.md in a Markdown viewer or on GitHub to view the documentation.
The diagrams render in viewers that support Mermaid.
